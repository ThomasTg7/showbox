# Plan 00 — Fundación · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Proyecto Next.js funcionando con base de datos, login de admin con lista blanca, sistema de diseño Guerra Campal, layouts público y admin, y utilidades transversales (publicación, auditoría, papelera).

**Architecture:** Monolito Next.js App Router. Lógica de dominio pura en `src/domain` (sin I/O, testeada con Vitest). Acceso a datos por feature en `src/features/<dominio>/{queries,actions}.ts` usando Drizzle sobre Postgres estándar. Tests de integración de BD con PGlite (Postgres en proceso, sin Docker).

**Tech Stack:** Next.js (última estable, App Router, `src/`), TypeScript strict, pnpm, Tailwind CSS v4, shadcn/ui (solo admin), Drizzle ORM + `postgres` (postgres.js), drizzle-kit, Better Auth, Zod, Vitest + Testing Library, PGlite, Playwright, Lenis, GSAP.

**Spec:** `docs/superpowers/specs/2026-09-28-guerra-campal-design.md`

## Global Constraints

- Identificadores de código en inglés; textos visibles en español (es-CL).
- Prohibido usar SDKs o features propietarias del proveedor de BD (Supabase Auth/Storage/RLS, Neon branching API). Solo `DATABASE_URL` Postgres estándar.
- Colores: `#000000`, `#0F0F0F`, `#1A1A1A`, `#2A2A2A`, `#FFFFFF`, `#A3A3A3`, `#FFB400`, `#FFC633`, `#E0A000`, rojo esquina `#D7263D`, azul esquina `#1E6FD9`. Texto sobre amarillo: negro.
- Fuentes: Anton (display), Barlow Condensed 500/600/700/800, Barlow 400/500/600.
- Toda animación respeta `prefers-reduced-motion: reduce` (se desactiva).
- Sin scroll horizontal de página en anchos ≥ 320 px.
- Contenido público visible solo si `deleted_at IS NULL` y (`status='published'` o (`status='scheduled'` y `publish_at <= now()`)).
- Toda acción de escritura del admin registra auditoría y exige sesión válida con email en lista blanca (verificado en el servidor, no solo en proxy/middleware).

## Review Focus

- Email en mayúsculas/espacios (`" Admin@X.cl "`) debe coincidir con la lista blanca normalizada (trim + lowercase).
- Login con Google de un email no autorizado no debe crear usuario ni sesión (no solo redirigir).
- Contenido `scheduled` con `publish_at` en el pasado debe verse público sin intervención; con `publish_at` nulo nunca.
- Purga de papelera: elementos con `deleted_at` hace exactamente 30 días menos 1 minuto no se purgan.
- Página pública a 320 px de ancho sin overflow horizontal (header, menú móvil, footer).
