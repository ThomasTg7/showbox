# Plan 01 — Medios (imágenes) · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Subir, recortar, ajustar, quitar fondo y servir imágenes con formatos fijos por tipo, usando almacenamiento portable.

**Architecture:** El navegador sube el original directo al almacenamiento con URL prefirmada (evita el límite de 4.5 MB de body en Vercel). El editor guarda solo parámetros (recorte, rotación, enfoque, ajustes); el servidor aplica esos parámetros con `sharp` y genera variantes WebP. Un `StorageDriver` abstrae disco local / S3 (R2, MinIO).

**Tech Stack:** sharp, @aws-sdk/client-s3 + @aws-sdk/s3-request-presigner, react-easy-crop, @huggingface/transformers (quitar fondo en Web Worker), isomorphic-dompurify (SVG), Zod.

**Spec:** `docs/superpowers/specs/2026-09-28-guerra-campal-design.md` (§5)

## Global Constraints

- Seguir `docs/convenciones.md` (patrones ya construidos y probados en Plan 00: actions, auth, correo, papelera, paginación, fechas, tests). Manda sobre lo que diga este plan si hay conflicto.
- Hereda las Global Constraints del Plan 00.
- Especificaciones exactas por tipo (`kind`):

  | kind | aspecto | recomendado | mínimo | variantes (ancho px) |
  |---|---|---|---|---|
  | fighter_body | 2/3 | 1200×1800 | 800×1200 | 400, 800, 1200 |
  | fighter_headshot | 1/1 | 800×800 | 400×400 | 200, 400, 800 |
  | event_hero | 16/9 | 1920×1080 | 1280×720 | 800, 1280, 1920 |
  | event_hero_mobile | 4/5 | 1080×1350 | 720×900 | 540, 1080 |
  | event_poster | 4/5 | 1080×1350 | 720×900 | 540, 1080 |
  | news_cover | 16/9 | 1600×900 | 1200×675 | 400, 800, 1600 |
  | gallery | libre | lado largo 2400 | lado largo 1200 | 800, 1600, 2400 |
  | sponsor_logo | caja 2/1 | 600×300 | 300×150 | 300, 600 (SVG sin variantes) |
  | og_image | 1200/630 | 1200×630 | 1200×630 | 1200 |
- Tamaño máximo 15 MB. Tipos aceptados: `image/jpeg`, `image/png`, `image/webp`, `image/svg+xml` (este último solo `sponsor_logo`).
- Bajo el mínimo: advertencia "La imagen es más chica que el mínimo recomendado (W×H) y puede verse pixelada." y se permite continuar.
- Nunca se escala hacia arriba: variantes con ancho mayor al recorte se omiten.
- El original siempre se conserva.
- Modelo de quitar fondo con licencia permisiva (Apache-2.0/MIT). Verificar licencia antes de fijar el modelo; candidato `Xenova/modnet`.

## Review Focus

- Foto de celular con orientación EXIF (rotada 90°) debe procesarse derecha (aplicar `sharp().rotate()` antes del recorte).
- PNG con transparencia en `fighter_body` debe conservar transparencia en WebP (no fondo negro).
- Recorte que roza el borde por redondeo (x+w = ancho+1) no debe fallar: se ajusta a los límites.
- SVG con `<script>` o `onload` debe quedar sanitizado.
- Subida abortada (sin `finalize`) no debe dejar filas `media` huérfanas visibles; originales huérfanos > 24 h se purgan con el cron del Plan 00.
